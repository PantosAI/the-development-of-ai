一、疲劳的本质定义

疲劳是机体复杂的生理生化变化过程，是指脑力或体力到达一定阶段时必然出现的一种正常的生理现象。它既标志着机体原有工作能力的暂时下降，又可能是机体发展到疾病状态的先兆。

核心特征：疲劳没有单一的全球机制（no global mechanism），其成因具有任务依赖性（task dependency）——导致疲劳的主导机制取决于疲劳性运动中所应激的具体生理过程。

二、疲劳的两大分类

维度中枢疲劳（Central Fatigue）外周疲劳（Peripheral Fatigue）
起源部位大脑 / 中枢神经系统（脑、脊髓）肌肉本身 / 神经肌肉接头
核心机制中枢神经系统对肌肉的最大激活能力下降肌肉纤维收缩力下降，动作电位传递障碍
关键症状失去动机、全身沉重感、注意力下降肌肉灼烧感、局部无力、疼痛
力量表现自主指令输出下降肌肉无法产生应有力量
恢复速度较慢，有时休息也不充分短暂休息后常可快速恢复
同义词神经疲劳、脊髓上疲劳局部肌肉疲劳、收缩疲劳

现实情况：中枢疲劳与外周疲劳往往共存并相互触发。疲劳的肌肉向神经系统发送更多应激信号，大脑随后主动降低运动指令以保护身体。

三、外周疲劳的深层生理机制

3.1 能量代谢崩溃：ATP耗竭

三磷酸腺苷（ATP）是肌肉收缩的唯一燃料。在接近最大强度的运动中，肌肉储存的ATP会在不到1秒内耗尽，因此必须持续再合成。

🔬 ATP再合成的三条主要通路
  • 磷酸肌酸（PCr）系统： PCr + ADP → ATP + Cr，供能最快但储量有限（约10秒耗尽）
  • 糖酵解系统： 肌糖原/血糖在无氧条件下分解为乳酸，快速生成ATP
  • 氧化磷酸化系统： 在线粒体中利用氧气将糖、脂肪、蛋白质彻底氧化，产能最大但速度较慢
疲劳触发点：当肌肉消耗ATP的速度超过再合成速度时，能量代谢即告失败。特别是在II型（快缩）肌纤维中，PCr储量迅速耗竭，而糖酵解速率不足以补偿ATP产量的下降，导致力量生成被迫降低。

3.2 代谢产物积累：Pi 与 H⁺ 的致命作用

ATP水解的最终产物和离子代谢物积累是外周疲劳的核心通路。以下物质在肌肉内积聚，直接抑制横桥形成与激活：

代谢物来源对肌肉收缩的影响
无机磷酸盐（Pi）ATP水解：ATP → ADP + Pi；PCr分解① 进入肌浆网并与Ca²⁺沉淀，降低游离Ca²⁺浓度
② 直接抑制肌动蛋白-肌球蛋白横桥的形成与激活
③ 降低肌浆网Ca²⁺释放通道的开放效率
氢离子（H⁺）糖酵解过程中产生；ATP水解① 降低肌浆pH（可降至6.2~6.5）
② 抑制Ca²⁺与肌钙蛋白的亲和力
③ 抑制肌球蛋白ATP酶活性
④ 干扰磷酸化酶和磷酸果糖激酶活性
乳酸糖酵解终产物（丙酮酸还原）传统认为乳酸直接导致疲劳，但现代研究证实：乳酸积累并非局部肌肉疲劳的主要原因，而是Pi和H⁺积累的标志物
ADP / AMPATP消耗后的产物AMP经AMP脱氨酶降解为IMP和氨；氨的积累与疲劳密切相关

3.3 兴奋-收缩耦联障碍（E-C Coupling Failure）

兴奋-收缩耦联是将电信号转化为机械收缩的关键过程，疲劳时该过程在多个环节受损：

1
动作电位传播障碍：高频刺激导致细胞外K⁺积累，使静息膜电位去极化，降低电压传感器（DHPR）的激活效率，进而减少肌浆网Ca²⁺释放。
2
Ca²⁺释放减少：肌浆网上的Ryanodine受体（RyR1）对Ca²⁺的释放能力下降。原因包括：① 膜电位变化；② 游离Mg²⁺增加（ATP下降导致Mg²⁺从ATP-Mg复合物中释放）；③ Pi进入肌浆网沉淀Ca²⁺。
3
Ca²⁺敏感性下降：H⁺和Pi的积累降低了肌钙蛋白对Ca²⁺的亲和力，使横桥循环效率下降。
4
结构蛋白损伤：在离心收缩中，连接肌浆网与T小管的junctophilin蛋白受损，破坏E-C耦联的结构基础。

3.4 神经肌肉接头功能障碍

神经肌肉接头是运动神经元轴突末梢与肌纤维的突触连接。反复刺激后，接头传递效率可逐渐下降：

  • 突触前膜乙酰胆碱（ACh）释放减少
  • 突触间隙乙酰胆碱酯酶活性变化
  • 突触后膜烟碱型受体脱敏

3.5 氧化应激与炎症反应

  • 活性氧（ROS）：长时间离心运动产生超氧阴离子，损伤肌细胞膜磷脂
  • 羟基自由基：在肌肉应激过程中生成，破坏DNA、脂质和其他生物分子
  • 炎症因子：IL-6、TNF-α等细胞因子在运动后升高，反映局部或全身炎症反应

四、中枢疲劳的深层生理机制

4.1 神经递质失衡假说

中枢疲劳源于中枢神经系统中多种神经递质的复杂相互作用，没有单一机制可以完全解释。

🧠 5-羟色胺（5-HT / 血清素）假说
  • 长时间运动中，支链氨基酸（BCAA）被肌肉氧化供能，血浆中BCAA浓度下降
  • BCAA与游离色氨酸竞争通过血脑屏障的同一转运系统
  • 当BCAA/色氨酸比值下降时，更多色氨酸进入大脑，转化为5-HT
  • 脑内5-HT积累 → 产生倦怠感、嗜睡感、神经驱动力丧失 → 中枢疲劳
🧠 多巴胺（DA）系统
  • 多巴胺由酪氨酸经酪氨酸羟化酶转化为L-DOPA，再转化为多巴胺
  • 多巴胺分泌与延迟疲劳和延缓耗竭相关
  • 黑质致密部（SNpc）多巴胺分泌减少 → 基底神经节激活受损 → 运动皮层刺激减少 → 中枢疲劳加剧
  • 长期运动训练可增加酪氨酸羟化酶基因表达，减少D2自身受体表达，改善多巴胺能功能
🧠 γ-氨基丁酸（GABA）系统
  • GABA是中枢神经系统主要的抑制性神经递质
  • 由谷氨酸脱羧酶（GAD65和GAD67）合成；GAD67负责90%以上的GABA产生
  • 高强度间歇训练（HIIT）后，感觉运动皮层GABA浓度显著升高，与血乳酸水平呈正相关
  • GABA增加 → 抑制神经传递 → 降低运动皮层输出 → 中枢疲劳
🧠 腺苷系统
  • ATP降解产生腺苷，腺苷在大脑中积累
  • 腺苷与A1/A2A受体结合，抑制神经元兴奋性
  • 促进睡眠感和疲劳感，降低觉醒水平和动机

4.2 运动皮层激活下降（Supraspinal Fatigue）

即使肌肉本身功能完好，运动皮层也无法充分驱动肌肉：

  • 最大随意收缩时，运动皮层输出细胞的兴奋性和抑制性反应均增加
  • 但皮层对肌肉的自愿激活能力下降（即存在"脊髓上疲劳"）
  • 经颅磁刺激（TMS）研究显示：静息期（silent period）约10秒恢复，兴奋性反应15~30秒恢复，而脊髓上疲劳约需1分钟恢复

4.3 肌肉传入反馈：III/IV类感觉纤维的作用

疲劳的肌肉通过III类（机械敏感）和IV类（代谢敏感）传入纤维向中枢神经系统发送信号：

  • 这些传入纤维对代谢物（如H⁺、K⁺、乳酸、ATP等）敏感
  • 信号上传至脊髓和大脑，抑制运动神经元池的兴奋性
  • 同时限制运动皮层（及其他下行通路）输出细胞的驱动
  • 这种机制是一种保护性反射，防止肌肉在代谢危机中继续受损
  • 实验证明：阻断肌肉血流使代谢物持续积累时，脊髓上疲劳持续存在；恢复血流后约30秒内自愿激活恢复

4.4 脊髓运动神经元池变化

  • 运动神经元的兴奋性受多种反射输入和内在特性变化的影响
  • 下行单胺能驱动（如5-HT、去甲肾上腺素）的神经调节效应改变运动神经元池的输入-输出特性
  • 运动神经元兴奋性降低 → 需要更大的下行驱动来维持相同输出 → 主观上感到"更费力"

4.5 心理疲劳与认知资源耗竭

心理疲劳（mental fatigue）是中枢疲劳的重要表现形式：

  • 前额叶皮层（理性中心）因能量不足而功能减弱，自控力下降
  • 杏仁核（情绪警报器）敏感度提升约300%
  • 即使是生活中的小事也容易被识别为"威胁"，引起皮质醇持续分泌
  • 去甲肾上腺素能神经递质系统参与调节努力感知；心理疲劳状态下，主观努力感知显著升高

五、疲劳发生的阶段性过程

第一阶段：早期代偿期

疲倦感轻微，作业能力不受影响或仅轻度下降。浓厚兴趣、特殊刺激、意志力可掩盖疲劳感，维持工作效率，但存在导致过劳的危险。此阶段以神经递质微调和PCr储量轻度下降为主。

第二阶段：功能下降期

作业能力下降趋势明显，主要影响工作质量。此阶段ATP再合成速率开始跟不上消耗，Pi和H⁺在肌细胞内积累，Ca²⁺释放效率下降，中枢激活开始减弱。

第三阶段：耗竭崩溃期

疲倦感强烈，作业能力急剧下降或出现波动（表明劳动者试图努力维持）。最终精疲力竭，操作紊乱，无法继续工作。此阶段涉及严重的能量代谢衰竭、广泛的E-C耦联障碍、显著的中枢神经递质失衡及保护性抑制机制全面激活。

6.2 氧化应激标志物

  • 脂质过氧化产物（MDA等）：反映ROS对细胞膜的损伤程度
  • 蛋白质羰基：反映蛋白质氧化损伤
  • 总抗氧化能力：反映机体清除自由基的能力

6.3 炎症标志物

  • 白细胞：运动后中性粒细胞和淋巴细胞 mobilization
  • IL-6：肌肉收缩时释放的"肌因子"，兼具促炎和抗炎双重作用
  • TNF-α：主要由巨噬细胞产生，运动后升高
  • CRP、IL-8、IL-10、热休克蛋白（HSP27/70）等也具有潜在诊断价值

七、疲劳的恢复过程

7.1 短时高强度运动后的恢复

恢复成分恢复时间机制
中枢疲劳（脊髓上）约2分钟内代谢物清除，神经递质再平衡
外周疲劳（E-C耦联相关）3~5分钟再灌注恢复，离子梯度重建
完全肌肉功能恢复数小时肌浆网Ca²⁺释放或敏感性持续受损

7.2 长时间低强度运动后的恢复

  • 自愿力量在最初几分钟内快速、部分恢复，主要归因于中枢（神经）成分的恢复
  • 但自愿激活能力可能在运动后20~30分钟内无法完全恢复
  • 外周疲劳对快速初始力量恢复贡献较小，且至少20~30分钟内不完全
  • 主观努力感知约需5分钟完全恢复
关键发现：长时间亚最大收缩后的中枢疲劳恢复比短时最大收缩更慢。其机制尚不完全清楚，可能与持续的III/IV类传入纤维活动、神经递质耗竭及中枢代谢物积累有关。

八、疲劳的整合模型

🔄 疲劳的级联反应全景图
  1. 起始触发：运动负荷 → 能量需求激增 → ATP消耗加速
  2. 能量危机：PCr耗竭 → 糖酵解代偿 → ADP/AMP/Pi/H⁺积累 → pH下降
  3. 外周障碍：Ca²⁺释放减少 + 敏感性下降 → 横桥循环效率降低 → 肌肉力量下降
  4. 传入信号：III/IV类传入纤维感知代谢危机 → 向脊髓和大脑发送抑制信号
  5. 中枢抑制：运动皮层输出降低 + 神经递质失衡（5-HT↑/DA↓）→ 动机丧失 + 努力感知升高
  6. 保护性终止：主观"无法继续" → 运动终止 → 进入恢复期

这一模型说明：疲劳不是简单的"能量用完"，而是一个涉及代谢、电生理、神经化学、心理感知多个层面的复杂调控过程。中枢神经系统在此过程中扮演着"守门人"的角色——即使肌肉仍有残余收缩能力，中枢保护性抑制也会阻止其继续工作。

九、疲劳如何摧毁免疫力——"一疲劳就感冒"的科学解释

你遇到的问题非常典型，核心是一个"疲劳→免疫崩溃→感染→恢复更慢→更容易疲劳"的恶性循环。要打破它，不能只靠"补"，必须从上游切断疲劳触发，同时加固免疫防线。

9.1 为什么你一疲劳就感冒？——五层免疫崩溃机制

层面发生了什么后果
能量危机线粒体功能障碍，ATP合成效率下降，细胞进入"节能模式"免疫细胞（NK细胞、T细胞）活性降低，杀菌能力下降
HPA轴紊乱长期/反复疲劳导致下丘脑-垂体-肾上腺轴失调，皮质醇节律异常皮质醇过高抑制免疫，过低则炎症失控
慢性炎症IL-6、TNF-α等促炎因子持续低度升高免疫系统被"慢性消耗"，遇到病毒时反应迟钝

核心结论：疲劳时你的身体已经处于"内忧外患"状态，病毒一来就挡不住。这不是"体质差"，而是疲劳管理系统的系统性崩溃。

9.2 疲劳削弱免疫的具体通路

9.2.1 先天免疫受损

  • NK细胞活性下降：连续几天睡眠不足6.5小时，NK细胞活性可下降70%，对病毒感染的第一道防线被击穿
  • 中性粒细胞吞噬能力下降：高糖饮食后5小时内，中性粒细胞的杀菌能力显著降低
  • 巨噬细胞功能受损：慢性疲劳状态下，巨噬细胞产生TNF-α和IL-1β的能力下降，抗原呈递效率降低

9.2.2 适应性免疫紊乱

  • Th1/Th2平衡偏移：疲劳状态下Th2反应相对增强，体液免疫亢进而细胞免疫受抑，对病毒（尤其是呼吸道病毒）的清除能力下降
  • 抗体产生延迟：B细胞分化为浆细胞的过程需要充足的能量和氨基酸供应，疲劳时这一进程受阻
  • 免疫记忆受损：反复疲劳会干扰记忆T细胞的维持和再激活

9.2.3 黏膜免疫屏障破坏

  • 呼吸道和消化道黏膜是病毒入侵的第一道物理屏障
  • 疲劳时黏膜分泌型IgA（sIgA）水平下降，病毒更容易突破黏膜防线
  • 上皮细胞紧密连接蛋白表达减少，通透性增加

9.2.4 炎症-免疫耗竭

  • 慢性低度炎症（"inflammaging"）使免疫系统长期处于"战备消耗"状态
  • 当真正的病原体入侵时，免疫细胞已经"精疲力竭"，无法发起有效的急性反应
  • 这就是为什么疲劳的人感冒后恢复也更慢——免疫系统已经"透支"

9.3 恶性循环图解

🔄 疲劳-免疫崩溃恶性循环
  1. 触发事件：熬夜、高压工作、过度运动、情绪应激
  2. 能量代谢崩溃：ATP耗竭 → 线粒体功能障碍 → 细胞进入节能模式
  3. HPA轴激活：皮质醇急性升高 → 暂时抑制免疫 → 为身体"争取时间"
  4. 神经递质失衡：5-HT↑/DA↓ → 倦怠感、失去动机 → 活动减少
  5. 免疫窗口期：NK细胞活性下降70% → 黏膜sIgA减少 → 病毒入侵成功
  6. 感染发生：感冒/发热 → 进一步消耗能量和免疫资源
  7. 恢复期延长：免疫系统"透支" → 恢复需要更长时间
  8. 再次易感：恢复不完全 → 稍有疲劳再次感染 → 回到步骤1

十、打破恶性循环：五层解决策略

🔴 第一层：识别并消除你的"疲劳触发器"（最关键）

很多人反复感冒不是因为体质差，而是因为疲劳模式固定且不自知。你需要做一个"疲劳日志"，连续记录2周：

日期：____年__月__日
疲劳前做了什么：____________
睡了多久：____小时（入睡__点，起床__点）
情绪状态：焦虑 / 压抑 / 平静 / 兴奋
是否感冒：是 / 否（症状：________）

常见触发器：

  • 睡眠不足或节律混乱：连续几天睡不够6.5小时，NK细胞活性可下降70%
  • 高强度工作后的"假放松"：周末报复性熬夜、刷手机到半夜，比工作还伤
  • 情绪高压：焦虑、压抑会直接升高皮质醇，压制免疫
  • 过度运动：如果你本身处于疲劳边缘，一次大强度运动会暂时抑制免疫（"开窗期"3-72小时）
  • 饮食不规律：长时间空腹或高糖饮食导致血糖过山车，加重炎症
行动要点：找到你的1-2个核心触发器，优先解决。这比吃任何保健品都有效。

🟠 第二层：建立"疲劳预警系统"

你现在的模式是：疲劳→感冒→才发现过头

要改为：预警信号→保护模式→阻止感冒

早期疲劳信号清单（出现2项以上就要进入"保护模式"）

早晨醒来仍觉疲惫，起床困难
下午3-4点注意力明显下降，需要咖啡续命
对平时喜欢的事提不起兴趣
轻微运动后肌肉酸痛超过48小时
睡眠质量变差（入睡难、易醒、多梦）
频繁打哈欠、眼睛干涩
食欲下降或异常渴望高糖食物

"保护模式"做什么

措施具体操作作用机制
强制早睡当晚比平时早1小时上床，手机放客厅睡眠是免疫修复的核心窗口，深度睡眠时T细胞增殖、细胞因子重新平衡
取消非必要活动推掉社交、取消加班、请假半天减少额外能量消耗，让免疫系统"休养生息"
工作节奏调整采用"番茄工作法+强制休息"，每25分钟休息5分钟避免认知资源持续耗竭，降低中枢疲劳累积
营养强化每餐增加优质蛋白（鱼/蛋/豆制品），额外补充维生素C 200mg免疫细胞本身就是蛋白质构成，维生素C支持中性粒细胞功能
避免额外刺激不喝咖啡、不喝浓茶、不看刺激内容让HPA轴有机会从过度激活中恢复

🟡 第三层：主动恢复，而不是被动休息

很多人疲劳了就"躺着刷手机"，这不是恢复，是另一种消耗。有效的主动恢复策略：

策略怎么做科学依据
睡眠债偿还连续3天保证7.5-8小时睡眠，固定起床时间（比固定入睡更重要）睡眠是免疫修复的核心窗口，深度睡眠时T细胞增殖、细胞因子重新平衡
低强度活动疲劳时做散步、拉伸、太极，而不是完全静止适度运动促进淋巴循环和免疫细胞巡逻，完全不动反而降低免疫
冷热交替温水淋浴后30秒冷水冲淋（或泡脚后冷水冲脚）刺激自主神经，改善HPA轴功能，增强应激适应
正念呼吸每天10分钟，4-7-8呼吸法（吸气4秒、屏息7秒、呼气8秒）降低交感神经兴奋，减少促炎因子，提升NK细胞活性
社交断联每天留出1小时"无信息时间"，不看手机信息过载是隐性疲劳源，持续激活HPA轴
日光暴露早晨起床后30分钟内接触自然光10-15分钟重置昼夜节律，促进皮质醇正常晨峰，改善夜间褪黑素分泌

🟢 第四层：加固免疫系统的日常养护

10.4.1 饮食策略

10.4.3 运动免疫策略

你现在的状态适合"中等偏低强度、规律、不过量"：

  • 推荐运动：快走、游泳、骑行、瑜伽、八段锦
  • 时长：每次30-45分钟
  • 强度：心率控制在（220-年龄）×60%-70%，或"能边运动边说话"的强度
  • 频率：每周4-5次，留出2-3天恢复
绝对避免：在已经感到疲劳时进行高强度间歇训练（HIIT）、长距离跑步、力量训练到力竭——这会让你的免疫"开窗期"正好撞上病毒暴露。运动后3-72小时是免疫抑制窗口，此时要特别注意防护。

10.4.4 肠道-免疫轴养护

🦠 为什么肠道决定免疫力？
  • 人体70%的免疫细胞位于肠道相关淋巴组织（GALT）
  • 肠道菌群产生的短链脂肪酸（SCFA）——尤其是丁酸——是结肠上皮细胞的主要能量来源，维持肠道屏障完整性
  • 菌群失调 → 肠通透性增加（"肠漏"）→ 细菌内毒素（LPS）入血 → 全身低度炎症 → 免疫资源被慢性消耗
  • 补充益生菌（乳杆菌、双歧杆菌）和益生元（菊粉、低聚果糖）可改善肠道菌群多样性

🔵 第五层：心理-神经-免疫调节

心理疲劳不仅是"感觉累"，它会通过神经内分泌通路直接影响免疫：

通路机制干预方法
HPA轴调节慢性压力 → 皮质醇持续升高 → 淋巴细胞凋亡增加、Th1/Th2偏移正念冥想、渐进式肌肉放松、规律作息
迷走神经刺激迷走神经是"抗炎反射"的主要通路；刺激迷走神经可降低TNF-α等促炎因子深呼吸、冷水洗脸、唱歌、冥想
社会连接社会孤立与免疫功能下降相关；亲密关系支持可缓冲压力对免疫的负面影响保持与亲友的定期高质量互动，避免社交孤立
自然暴露森林浴（Shinrin-yoku）可降低皮质醇、血压和炎症标志物每周至少2次，每次30分钟以上的自然环境中活动

十一、需要排查的潜在问题

如果你的"一疲劳就感冒"已经持续超过6个月，或者每次感冒后恢复时间超过2周，建议去医院做以下检查：

检查项目排查什么异常时的可能诊断
血常规 + 淋巴细胞亚群白细胞总数、中性粒细胞、淋巴细胞比例，NK细胞活性白细胞减少症、淋巴细胞亚群失衡、NK细胞功能低下
免疫球蛋白（IgG/IgA/IgM）体液免疫功能低丙种球蛋白血症、选择性IgA缺乏
甲状腺功能（TSH/FT3/FT4）甲状腺功能甲减是隐性疲劳和免疫低下的常见原因
血清维生素D25-OH-D水平缺乏（<20 ng/mL）与反复呼吸道感染高度相关
铁蛋白 + 血清铁铁储备隐性缺铁会导致疲劳和免疫下降，女性更常见
HPA轴功能评估24小时尿游离皮质醇或唾液皮质醇节律肾上腺疲劳/皮质醇节律紊乱

建议就诊科室：如果系统检查后无明确器质性疾病，但症状持续，建议挂风湿免疫科或全科医学科做系统评估，排除慢性疲劳综合征（CFS/ME）、自身免疫倾向等潜在问题。

  • 疲劳恢复速度是否加快（目标：从"疲劳后3-5天才能恢复"变为"1-2天内恢复"）
  • 睡眠质量是否改善（目标：入睡时间<30分钟，夜间醒来≤1次）
  • 日常精力水平是否提升（目标：下午不需要咖啡也能维持注意力）

十三、感染早期的"黄金48小时"干预

既然你知道自己一疲劳就容易感冒，就要学会在症状刚出现时快速反应，阻止它发展成发热：

第一天（喉咙痒/轻微鼻塞/乏力/头痛）

立即停掉所有非必要活动，进入"全休模式"——请假半天比硬撑3天值得多
大量温水：每小时200-300ml，保持呼吸道黏膜湿润，增强黏液-纤毛清除功能
温盐水漱口：3-4次/天（240ml温水+1/4茶匙盐），减少咽部病毒载量
补充维生素C 500mg + 锌15mg，分2次服用
保证10小时睡眠，比平时早睡2小时
清淡饮食：粥、蔬菜汤、蒸蛋，避免油腻和甜食
室内通风：每天开窗2-3次，每次30分钟

第二天（症状加重但未发热）

继续上述所有措施
饮用姜茶/蜂蜜柠檬水（1岁以上）：姜中的姜辣素具有抗炎和抗病毒作用
生理盐水洗鼻：每天2次，减少鼻腔病毒负荷
蒸汽吸入：热水+几滴尤加利精油（或仅用热水），缓解鼻塞
监测体温：每4小时测一次，记录变化趋势

出现以下情况立即就医

  • 体温 ≥ 38°C 持续超过24小时
  • 症状超过3天无缓解或持续加重
  • 出现呼吸困难、胸痛、意识模糊
  • 咳嗽伴有黄绿色脓痰或血丝
  • 咽痛剧烈伴吞咽困难
  • 你属于高危人群（老年人、孕妇、有基础疾病者）

就医目的：排除流感、支原体肺炎、新冠等，必要时使用抗病毒药物或抗生素（仅在细菌感染时）。
