0030 秒上手 · 3 步法

临床医生（不限科室）看舌的统一 SOP。任何场景下先按这 3 步走，再深入具体征象。

1

看舌质（5 项）

  • 颜色：淡白 / 淡红 / 红 / 绛 / 青紫
  • 形状：胖 / 瘦 / 老 / 嫩
  • 齿痕、点刺、裂纹
  • 舌下静脉（曲张 → 瘀血）
  • 整体神气（有神 / 少神 / 无神）
2

看舌苔（5 项）

  • 颜色：白 / 黄 / 灰 / 黑
  • 厚薄：见底 / 不见底
  • 润燥：水滑 / 干燥
  • 腐腻：腐渣 / 油腻黏腻
  • 剥落：有 / 无 / 花剥
3

看分区（8 区）

  • 上焦：心 / 肺
  • 中焦：脾 / 胃 / 肝 / 胆
  • 下焦：肾 / 膀胱 / 肠
  • 特殊：心脑 / 颈椎 / 肩 / 乳腺

临床铁律

舌质比舌苔重要——舌质是本（脏腑气血），舌苔是标（邪正消长）。

苔突然退去 / 花剥 → 胃气大伤，警惕。

看动态不看快照——单次意义有限，3-7 天变化曲线更有价值。

027 种不正常舌象速查

来自你的笔记核心内容：凹 / 凸 / 缺损 / 白苔 / 黄苔 / 黄腻苔 / 红点。每种配现代医学对应可能。

气虚

① 凹舌

代表：气血不足
现代医学可能：贫血、慢性疲劳、低蛋白血症、营养不良、消化吸收差
气滞

② 凸舌

代表：胀气（气滞）
现代医学可能：胃肠胀气、功能性消化不良、肠梗阻早期、便秘、菌群失调
虚损

③ 缺损舌

代表：脏腑功能下降
现代医学可能：对应区域脏器功能减退（如心脑区缺损 = 心肌缺血 / 脑供血不足）、慢性病后期
寒

④ 白苔

代表：寒
现代医学可能：表寒证（外感风寒）、阳虚内寒、低代谢状态、甲状腺功能减退、慢性感染
热

⑤ 黄苔

代表：热
现代医学可能：细菌性炎症（呼吸道/消化道/泌尿道）、发热、感染性疾病、口腔卫生差
湿热

⑥ 黄腻苔

代表：湿热
现代医学可能：胆道感染、肝炎、胰腺炎、消化道湿热证、长期饮酒、高脂血症
炎症

⑦ 红点

代表：炎症堵（局部充血 / 瘀热）
现代医学可能：对应区域急性炎症、黏膜充血、微循环障碍、过敏反应

038 大分区详解

每个分区：位置 / 中医含义 / 现代医学对应 / 红旗信号 / 处理建议

① 心区 舌尖正中
上焦
中医主血脉、神志
西医心血管 + 自主神经
凹陷心气虚 → 心慌、心悸、气短
发红心火旺 → 失眠、烦躁、口疮
红点心肌炎早期 / 交感亢进
② 肺区 舌尖 1/3
上焦
中医主气、司呼吸、宣发肃降
西医呼吸系统 + 皮肤屏障
凹陷肺气虚 → 易感冒、气短、汗多
白腻痰湿壅肺 → 慢支、哮喘
黄苔肺热 → 急性上感、肺炎
③ 脾区 舌中偏左
中焦
中医主运化、统血、升清
西医消化吸收 + 免疫 + 造血
凹陷脾虚 → 食少、便溏、乏力
齿痕脾虚湿盛 → 慢炎、低蛋白
裂纹脾胃阴虚 → 慢性胃炎
④ 胃区 舌中偏右
中焦
中医主受纳、腐熟水谷
西医胃 + 食管 + 部分肝
黄腻胃热 / 食积 → 口臭、嗳气
剥苔胃阴虚 → 萎缩性胃炎（警惕）
干燥津液不足 / 脱水
⑤ 肝区 舌右侧（胆对侧）
中焦
中医主疏泄、藏血
西医肝脏 + 情志调节
紫暗肝郁血瘀 → 脂肪肝、肝硬化
红点肝火旺 → 高血压、甲亢
凹陷肝血虚 → 眩晕、月经量少
⑥ 胆区 舌左侧（肝对侧）
中焦
中医藏与排泄胆汁
西医胆囊 + 胆道系统
黄腻肝胆湿热 → 胆囊炎、胆石症
凸起胆气郁结 → 胁胀、口苦
红点急性胆道感染
⑦ 肾区 舌根两侧 ⊗
下焦
中医藏精、主水、主骨生髓
西医肾 + 内分泌 + 生殖
凹陷肾虚 → 腰膝酸软、听力下降
发红阴虚火旺 → 盗汗、失眠
无苔肾阴大亏 → 重症（警惕）
⑧ 膀胱/肠区 舌根正中 + 膀胱 ⊗
下焦
中医膀胱主气化、肠主传导
西医泌尿 + 下消化道
白腻寒湿下注 → 尿频、便溏
黄腻湿热下注 → 尿路感染、痔疮
凹陷气化不利 → 慢性盆腔炎

04女性专属公式 · 舌 + 经

直接来自你的笔记：心脑 / 颈椎 / 肩周 / 乳腺 四大妇科相关区域。女性患者（尤其经期前后）必看。

① 心脑区（舌根后部）

凹陷
心气不足 → 心慌、心悸
发红
心火大 → 烦躁、心烦、心急、失眠多梦
发白
心血虚 → 心慌、胸闷
红点
炎症 → 头痛、头胀、心慌不舒服
缺损
心肌缺血 / 脑供血不足 → 心慌、心率不齐、头晕

② 颈椎区（舌中前部）

凸出（孩子）
扁桃体肿大 / 腺样体肥大
凸出（成人）
颈椎变形、骨质增生
凹陷
颈椎气血不足 → 肩颈僵硬、易落枕
红点
颈椎炎症、不舒服

③ 肩周区（舌两侧偏下）

凹陷
肩周气血不足、活动受限
红点
肩周区炎症 → 胀、难受、活动痛

④ 乳腺区（舌中两侧）

凹陷
乳腺气血不足 → 胸下垂、松弛
红点
乳腺增生 / 结节（建议 B 超复查）
凸出
乳腺肿块可能（必查）

女性临床实操建议

经期前后对比——经前舌象偏红偏腻（气血涌动），经后偏淡偏薄（气血流失）。对比可判断气血储备。

孕前必看——舌根无苔、舌淡胖 = 肾气不足，建议调理再孕。

更年期——舌红少苔 + 盗汗 = 阴虚火旺；舌淡胖有齿痕 = 阳虚水泛。

05现代医学红旗征

现代医学必须警惕的舌象 —— 西医教材覆盖不足，本节是临床医生最该补的部分。

高

🍓 草莓舌

舌乳头红肿突出、舌面鲜红如草莓表面
必查：猩红热 / 川崎病 / 中毒性休克综合征 / 链球菌感染
动作：立即血常规 + CRP + 血培养 + 咽拭子
高

🪞 镜面舌 / 牛肉舌

舌乳头萎缩，舌面光滑发红如镜面
必查：缺铁性贫血 / 维生素 B12 缺乏 / 叶酸缺乏 / 恶性贫血
动作：血常规 + 铁蛋白 + B12 + 叶酸 + 网织红
中

🗺️ 地图舌

游走性环状红斑，边界清晰、形状日变
可能：多为良性（游走性舌炎），少数伴银屑病 / 莱特尔综合征 / 1 型糖尿病
动作：详询皮肤、关节症状，必要时皮肤科会诊
高

⬜ 白斑 / 毛舌

不能擦去的白斑，或黑毛样舌苔
必查：口腔白斑（癌前病变）/ 口腔念珠菌病 / 毛舌（真菌/抗生素后）
动作：口腔科活检（白斑不能擦去 = 高危）
高

🔵 舌下静脉曲张

舌下静脉直径 > 2.7mm 或伴迂曲怒张
必查：右心衰 / 门脉高压 / 慢性肺病 / 瘀血体质
动作：心脏彩超 + 肝胆 B 超 + BNP
中

👅 巨舌 / 齿痕舌

舌体肥大、边缘有牙齿压痕
可能：甲减 / 淀粉样变 / 肢端肥大症 / 睡眠呼吸暂停 / 水肿
动作：甲功 + 睡眠监测 + 心肾功能
中

🔴 黑苔

舌苔变黑（排除染色后）
可能：长期抗生素 / 霉菌感染 / 尿毒症 / 重症感染 / 化疗后
动作：排查霉菌感染 + 肾功能 + 用药史
中

⚪ 裂纹舌

舌面深浅不一裂纹（排除先天沟纹舌）
可能：维生素 B 族缺乏 / 慢性萎缩性胃炎 / 干燥综合征 / 梅毒性舌炎
动作：维生素检测 + 自身抗体 + 胃镜

06临床陷阱 · 6 个常见误判

这些"假象"会让你的判断跑偏。看完这张表，门诊里少犯 80% 的舌诊错误。

染苔
食物 / 药物 / 饮料 会改变舌苔颜色。
牛奶 → 白苔；咖啡 / 茶 / 酱油 → 黄褐苔；橘子 / 维生素 B2 → 黄苔；蓝莓 / 铁剂 → 黑苔。
对策：问诊必问"半小时内吃过什么、喝过什么"。
刮苔
饭后 / 刷牙后 苔会变薄甚至暂时消失。
对策：统一晨起空腹、刷牙前、未进食 看舌（门诊难实现，至少要"未进食 1 小时"）。
伸舌太久
伸舌超过 10 秒 舌会充血，颜色从淡红 → 红，影响判断。
对策："伸、读、收"3 秒内完成，必要时让患者休息后再看一次。
光线
白炽灯 / 黄光 看舌会偏黄；冷白光 / 自然光 最准。
对策：门诊用 LED 自然光，避开窗帘遮挡；夜间查房用手电筒侧光。
动态 vs 静态
单次舌象 意义有限。晨起 vs 饭后 vs 睡前差异巨大。
对策：住院病人每天看一次，连续 3-7 天看趋势；门诊病人问"最近一周舌苔变化"。
位置记忆
"舌尖看心肺"是临床经验，不是解剖事实。 舌面分区不能等同于 CT 解剖定位。
对策：分区用于"方向性判断"，最终需结合症状、体征、检验检查确诊。

07AI 视角补充 · Mavis

三个 AI 视角的洞察，不在教科书里，但可能是未来 5-10 年最值得关注的舌诊方向。

⚡ AI INSIGHT

1. 舌苔的"物质本质"决定了它为什么能反映全身

舌苔 = 丝状乳头角化上皮 + 食物残渣 + 细菌 + 脱落细胞 + 渗出液。

厚薄 = 角化速度 vs 脱落速度的比值。颜色 = 局部微生物群 + pH + 局部血氧。

洞察：舌苔本质是消化道微生态 + 局部循环 + 免疫的外显。"一张嘴看全身"不是玄学，是解剖学事实。

2. 现代研究正在"接住"舌诊

近 10 年舌诊研究在 PubMed 上的发文量增长 3 倍，重点方向：

舌苔微生物组

HP 感染者、糖尿病患者、IBS 患者的舌苔菌群结构有显著差异（已被多组学验证）

AI 图像识别

舌象 + 深度学习在胃癌、糖尿病筛查上已有 prototype，灵敏度 80-90%

舌下微循环

舌下静脉直径 + 迂曲度 = 全身微循环的可视化窗口（比甲襞微循环更易观察）

动态时间序列

同一患者 7-30 天的舌象变化曲线 = 真实"动态生物标志物"，比单次影像更稳定

3. 一个反常识的临床判断

教科书说"苔黄=热"、"白=寒"，但真正临床上看舌，重点是"动态变化"而不是"单次快照"。

同一个患者：晨起 vs 饭后 vs 睡前，舌象差异巨大。真正有经验的医生看舌，是看 3-7 天的舌象变化曲线，不是看一次。

洞察：AI 舌诊的下一个突破点一定是"时间序列建模"，而不是"单图分类"。这是临床医生最值得深挖的科研方向。

临床医生可落地的副业方向

方向 1：AI 舌诊辅助诊断工具——基于开源数据集（GitHub: OralCancerDataset, TCIA）训练专科舌诊模型，配合你的临床专业做产品。

方向 2：舌诊健康科普内容——小红书 / 视频号上的"舌诊+西医解读"差异化内容，目前是蓝海。

方向 3：体质辨识 SaaS 工具——给中医馆 / 体检中心做舌诊 + 体质辨识的轻量级工具，订阅制收费。
