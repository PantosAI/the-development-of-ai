SECTION 04

门诊常见病种

基于沿海农村 + 县域高血压/糖尿病流行病学（高血压患病率 27.6%、糖尿病前期 38%）。临床观察排序，仅供基层医生快速对照。

呼吸系统 · 占比最高

上感 / 支气管炎 / 慢阻肺

  • 普通感冒、急性咽/扁桃体炎
  • 急性气管-支气管炎
  • COPD 稳定期随访
  • 过敏性鼻炎（沿海 + 农业粉尘）
  • 哮喘轻度发作
冬季高发；海风 + 室内燃煤 = 慢阻肺高危人群
频次：极高
心血管 · 慢性病

高血压 / 冠心病

  • 原发性高血压（基层最大病种）
  • 高血压前期管理
  • 冠心病稳定期随访
  • 慢性心衰 NYHA II-III 级
  • 心律失常（房颤、室早）
18 岁以上人群高血压患病率 27.6%；超重 + 高盐饮食是主要驱动因素
KAP 调查患病率 27.6% 公卫随访主体
内分泌 · 代谢

2 型糖尿病 / 前期

  • 2 型糖尿病用药调整
  • 糖尿病前期干预
  • 高脂血症、肥胖
  • 甲状腺疾病（甲亢/甲减/结节）
  • 痛风 / 高尿酸血症
糖尿病前期在农村人群占比约 38%；与肥胖、饮酒显著相关
前期患病率高
消化系统

胃肠炎 / 慢性胃病

  • 急性胃肠炎（食源性高发）
  • 慢性胃炎 / 胃食管反流
  • 消化性溃疡
  • 胆囊炎 / 胆石症
  • 便秘 / 功能性消化不良
海产品摄入多 + 饮酒文化 → 胆道疾病不少见
儿科

儿童常见病

妇产科

孕产 / 妇科

  • 产后访视、母乳喂养
  • 妇科炎症（阴道炎、宫颈炎）
  • 月经失调、围绝经期
  • 两癌筛查（宫颈/乳腺）
本镇农村妇女两癌筛查是公卫重点
骨关节 · 老年

颈肩腰腿痛

  • 膝关节炎（重体力劳动 + 沿海湿冷）

  • 类风湿性关节炎

皮炎 / 中耳炎 / 结膜炎

SECTION 05

急诊常见病种

本节重点标注本地区相对特殊的急诊情境。基层首诊后胸痛、卒中、严重创伤立即转县人民医院。

心脑血管 · 致命

急性心梗 / 脑卒中

  • ST 段抬高型心肌梗死
  • 急性脑梗死（发病 4.5h 溶栓窗）
  • 脑出血 / SAH
  • 高血压急症 / 亚急症
  • 急性心衰、恶性心律失常
⚠ 高血压患病率高（27.6%）+ 老龄化 = 卒中、心梗第一致死因素。村卫生室应能完成首份心电图 + 远程上传
第一死因 黄金窗抢救
创伤 · 农业高发

农机伤 / 交通事故

  • 农机绞伤、碾压伤（收割/插秧季）
  • 车祸伤（县域主干道）
  • 高处坠落（建筑/仓库）
  • 骨折（髋部、脊柱、四肢）
  • 电击伤、热烧伤
⚠ 农忙 5-6 月、10-11 月农机伤高发；建议卫生院备好清创+止血+固定器材
季节性高发
中毒 · 沿海农业高发

农药 / 食物中毒

  • 有机磷农药中毒（农业生产高发！）

  • CO 中毒（冬季取暖）
  • 酒精中毒、急性药物中毒
  • 河豚 / 织纹螺中毒（沿海）
⚠ 有机磷中毒是本地区急诊特色——镇卫生院须 24h 备阿托品 + 氯解磷定

SECTION 07

地区特色与高危警示

基于"农业 + 沿海 + 老龄 + 化工业"复合背景，下列情境需要基层医务人员重点关注。

⚠ 复合暴露下的"地方病谱"

🌾
农业（稻·蒜·麦）为主 农药暴露（有机磷、百草枯禁用但仍存在）、农机伤、过敏性鼻炎、"双抢"中暑、慢性腰肌劳损——农忙 5-6 月、10-11 月急诊量上升
🌊
沿海 + 主干河道岸线 34.8km 海产品过敏、河豚/织纹螺中毒、溺水、海水刺伤感染（弧菌/Vibrio）、风湿性疾病高发、碘摄入与甲状腺疾病
🧓
人口老龄化（6 万户籍） 高血压患病率 27.6%、糖尿病前期 38%、脑卒中、心衰、慢阻肺、肿瘤、骨质疏松性骨折、痴呆——慢病管理是基层最大工作量
🏭
工业园（纺织·机械·香料·食品） 职业性皮肤病、化学性鼻炎/哮喘、噪声聋、外伤；工伤需走工伤保险路径
🧂
饮食结构：高盐 + 酒文化 腌制菜（白蒜、大蒜制品）+ 海产 + 饮酒 → 高血压、胃癌、食管癌、肝硬化发病率高
📚
健康素养偏低（2007 KAP 调查） 高血压知识知晓率 12.9%-88.1%，行为形成率 10.8%-80.2%；19.8% 从未测过血压——健康教育与早期筛查是关键突破口
🎗
肿瘤筛查是"本地名片" 结直肠癌、前列腺癌、乳腺癌、宫颈癌为重点筛查病种；县财政每年 1000 万 + 公益项目；累计筛查 30 万+，新发 728 例，早期癌 459 例
