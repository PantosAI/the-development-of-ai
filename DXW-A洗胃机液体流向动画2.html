三路液体如何区分

清水 / 洗胃液 来源：进液桶（温开水或生理盐水等洗胃液）。
去向：进液口 → 冲泵 → 冲阀 → 压力阀 → 胃管口 → 胃管 → 胃内。
特点：全程不与胃内容物混合时为清澈蓝色。
混合物 来源：洗胃液在胃内与胃内容物（食物残渣、毒物）混合后的洗出液。
去向：胃 → 胃管 → 胃管口 → 吸阀 → 吸泵 → 一级 → 二级过滤瓶 → 排污口 → 污物桶。
特点：呈黄褐色浑浊；每洗一轮被稀释一次而逐渐变清（洗至澄清无异味为终点）。
污物 来源：混合物经两级过滤瓶时被截留的固体残渣（食物渣、药渣、絮状物）。
去向：沉积在一、二级过滤瓶底部与污桶底部，需倒掉、洗净后重新加满清水再用。
特点：与液体分开，不进入胃管与进液管路。

四种工作模式（对应面板按键）

关停机，电源指示灯熄灭（自控必须用“关”键才能停止）。
手吸自锁键：吸液泵工作，把胃内液体吸出、经过滤瓶排入污桶；再按一次解除。
手冲自锁键：冲液泵工作，把洗胃液从进液桶经胃管冲入胃；再按一次解除。
自控不自锁：进入自动洗胃，先吸液后冲液，自动循环（先出液后进液）。
提示手吸 / 手冲 互为自锁键，不能同时按下（面板右侧警示：严禁同时按两个以上键）；切换模式前先按“关”。

操作与安全要点（据使用说明书与实机面板）
① 严禁同时按两个以上键，否则可能烧断熔丝管；本演示中手吸与手冲同按即判为故障停机。
② 机器带电运转前，须先在两只过滤杯（过滤瓶）内分别加满清水；两只过滤瓶不得装错，污物满应立即停机倒掉、洗净后重新加半瓶以上清水。
③ 切勿将胃管插入气管；昏迷患者去枕平卧、头偏向一侧。洗胃过程中持续观察面色、呼吸、脉搏、血压及瞳孔。
④ 禁忌：吞服强酸强碱等腐蚀性物质、消化性溃疡、食管阻塞、食管静脉曲张、胃癌者不宜洗胃；出现腹痛、吸出液呈血性应立即停止洗胃。
⑤ 中毒物质不明时，抽出的胃内容物（第一次抽出物）应立即送检。
⑥ 终末处理：排空污桶、清洗管路与过滤瓶后消毒，机器终末消毒并记录。
